Installer le certificat de sécurité

Cette installation locale utilise un certificat SSL auto-signé. Pour que vos navigateurs reconnaissent les connexions comme sécurisées, installez ce certificat racine sur vos appareils.

⬇ Télécharger le certificat root.crt
Note : À faire une seule fois par appareil. Nécessaire pour utiliser le micro.

🪟 Windows

  1. Double-cliquez sur le fichier root.crt téléchargé
  2. Cliquez sur Installer le certificat
  3. Choisissez Emplacement du magasin : Utilisateur courant
  4. Cliquez sur Suivant, puis sélectionnez « Autorités de certification racines de confiance »
  5. Terminez l'assistant et confirmez les fenêtres de sécurité

🍎 macOS

  1. Ouvrez le fichier root.crt (il se lance dans le Trousseau d'accès)
  2. Dans le Trousseau d'accès, double-cliquez sur le certificat ajouté
  3. Dans la section Confiance, mettez « Utiliser ce certificat : » sur Toujours approuver
  4. Fermez la fenêtre et entrez votre mot de passe si demandé

📱 iPhone / iPad

  1. Ouvrez Safari et accédez à cette même page
  2. Téléchargez le certificat — un profil sera téléchargé
  3. Allez dans Réglages — vous verrez un profil en attente en haut
  4. Touchez-le, puis Installer et entrez votre code d'accès
  5. Allez ensuite dans Réglages > Général > Informations
  6. Descendez jusqu'à Réglages des certificats et activez la confiance pour ce certificat

🤖 Android

  1. Ouvrez Chrome et accédez à cette page, téléchargez le certificat
  2. Allez dans Paramètres > Sécurité (ou Sécurité et confidentialité)
  3. Sélectionnez Installer un certificat à partir du stockage (ou « Certificats CA »)
  4. Choisissez le fichier root.crt téléchargé
  5. Nommez-le et confirmez l'installation
